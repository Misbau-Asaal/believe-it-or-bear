TikTok login

One-time setup: connect the Believe It Or Bear TikTok account to the posting workflow.

1. Paste the Client key of your TikTok app (TikTok for Developers → your app → Sandbox → app details).
Only the Client key, never the Client secret. It stays in this page and goes only to TikTok.

2.

Log in with the Believe It Or Bear TikTok account (it must be a target user in the Sandbox).

Now, within a few minutes (the code works once and expires quickly):
GitHub repo → Actions → Post to TikTok and Instagram → Run workflow → paste it into tiktok_code, leave episode empty → Run workflow.
